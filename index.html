SAPED

Sistema de Apoio ao Processo de Ensino e Desenvolvimento

Projeto Acadêmico de Engenharia de Requisitos

📖 Sobre o Projeto

O SAPED (Sistema de Apoio ao Processo de Ensino e Desenvolvimento) foi desenvolvido como projeto acadêmico da disciplina de Engenharia de Requisitos, utilizando um estudo de caso baseado no Ministério de Minas e Energia (MME). O projeto teve como objetivo aplicar técnicas de elicitação, análise, especificação e validação de requisitos para um sistema de apoio aos processos institucionais.

🎯 Objetivos

  • Levantamento de requisitos
  • Análise das regras de negócio
  • Modelagem UML
  • Prototipação de interfaces
  • Documentação técnica
