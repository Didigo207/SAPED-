SAPED

Sistema de Apoio ao Processo de Ensino e Desenvolvimento

Projeto Acadêmico de Engenharia de Requisitos

🌟 Visão Geral

O SAPED (Sistema de Apoio ao Processo de Ensino e Desenvolvimento) foi desenvolvido como projeto acadêmico da disciplina de Engenharia de Requisitos, utilizando um estudo de caso baseado no Ministério de Minas e Energia (MME).

O projeto teve como foco a aplicação das principais técnicas de Engenharia de Requisitos, incluindo elicitação, análise, especificação, validação e documentação de requisitos, além da modelagem de processos e da criação de protótipos para apoiar o desenvolvimento de um sistema de informação.

Durante o desenvolvimento, foram produzidos artefatos essenciais, como levantamento de requisitos, casos de uso, diagramas UML, documentação técnica e protótipos de interface, proporcionando uma visão prática do ciclo inicial de desenvolvimento de software.

📖 Sobre o Projeto

O SAPED (Sistema de Apoio ao Processo de Ensino e Desenvolvimento) foi desenvolvido como projeto acadêmico da disciplina de Engenharia de Requisitos, utilizando um estudo de caso baseado no Ministério de Minas e Energia (MME). O projeto teve como objetivo aplicar técnicas de elicitação, análise, especificação e validação de requisitos para um sistema de apoio aos processos institucionais.
